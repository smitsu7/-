# IIP X-13 Excel VBA

Windows版Excelで使う季節調整ツールのVBAソースです。ブラウザに表示したコードをコピーしてブックを作れます。

## 初めて使う方へ

**[ブックの作成手順を開く](iip-x13-vba/README.md)**

モジュールの作成、コードの貼付け、初期化、1系列の試算まで順に説明しています。X-13のASCII版・HTML版に対応しています。

- [貼り付け用コード](iip-x13-vba/paste)
- [日本語コメント付きソース](iip-x13-vba/readable)

X-13実行ファイルと入力データは含めていません。用意するファイルと設定方法は、上の作成手順に記載しています。
